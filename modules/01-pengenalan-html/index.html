📖 Pendahuluan & Tujuan Pembelajaran

Selamat datang di modul pertama! Di sini Anda akan mempelajari fondasi dari setiap halaman web: HTML (HyperText Markup Language). Kami akan membahas apa itu HTML, bagaimana struktur dokumen HTML, dan elemen-elemen dasar yang sering digunakan.

Tujuan pembelajaran:

  • Memahami peran HTML dalam pengembangan web.
  • Mengenal struktur dasar dokumen HTML.
  • Mampu menulis elemen HTML dasar (heading, paragraf, tautan, gambar, daftar).
  • Mengerti pentingnya elemen semantik untuk aksesibilitas dan SEO.

🧠 Penjelasan Konsep

Apa itu HTML?

HTML (HyperText Markup Language) adalah bahasa markup standar yang digunakan untuk membuat dan menyusun halaman web. HTML memberikan struktur dasar pada konten yang Anda lihat di browser, seperti teks, gambar, tautan, formulir, dan lainnya.

HTML bekerja bersama dengan CSS (untuk tampilan) dan JavaScript (untuk interaktivitas) untuk membangun pengalaman web yang lengkap.

Struktur Dasar Dokumen HTML

Setiap dokumen HTML memiliki kerangka wajib seperti di bawah ini:

📄 HTML 
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Judul Halaman</title>
  </head>
  <body>
    <!-- Konten utama ditulis di sini -->
  </body>
</html>
  • <!DOCTYPE html> — deklarasi tipe dokumen (HTML5).
  • <html> — elemen akar, mencakup seluruh halaman.
  • <head> — berisi informasi meta, judul, dan tautan ke CSS/JS.
  • <body> — tempat semua konten yang terlihat oleh pengguna.

Elemen Dasar HTML

Heading — gunakan <h1> sampai <h6>.

📄 HTML
<h1>Judul Utama</h1>
<h2>Subjudul</h2>
<h3>Bagian lebih kecil</h3>

Paragraf — gunakan <p>.

📄 HTML
<p>Ini adalah sebuah paragraf.</p>

Tautan — gunakan <a href="url">.

📄 HTML
<a href="https://example.com">Kunjungi situs contoh</a>

Gambar — gunakan <img src="gambar.jpg" alt="deskripsi" />.

📄 HTML
<img src="logo.png" alt="Logo VITH Education" width="200" />

Daftar — tak berurutan (<ul>) dan berurutan (<ol>).

📄 HTML
<ul>
  <li>Item pertama</li>
  <li>Item kedua</li>
</ul>

<ol>
  <li>Langkah 1</li>
  <li>Langkah 2</li>
</ol>

Elemen Semantik

Elemen semantik memberikan makna pada struktur, membantu mesin pencari dan pembaca layar memahami konten. Contoh: <header>, <nav>, <main>, <section>, <article>, <footer>. Modul berikutnya akan membahasnya lebih dalam.

💻 Code Block / IDE Snippet

Berikut adalah contoh kode HTML lengkap dengan struktur dan elemen dasar:

📄 HTML 
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Halaman Pertama Saya</title>
</head>
<body>
  <h1>Selamat Datang!</h1>
  <p>Ini adalah halaman web pertama saya. Saya belajar HTML.</p>
  <a href="https://example.com">Kunjungi contoh</a>
  <img src="https://via.placeholder.com/150" alt="Placeholder" />
  <ul>
    <li>Poin 1</li>
    <li>Poin 2</li>
  </ul>
</body>
</html>

📌 Tips & Aksesibilitas

💡
Tips Developer: Selalu gunakan atribut alt pada gambar untuk memberikan deskripsi teks alternatif. Ini penting bagi pengguna dengan pembaca layar dan juga membantu SEO.
⚠️
Peringatan: Pastikan struktur heading (<h1> – <h6>) berurutan dan tidak melompat. Gunakan <h1> hanya sekali per halaman untuk judul utama.

🏆 Mini Challenge

📝 Tugas Anda

Buatlah sebuah halaman HTML sederhana yang berisi:

  • Sebuah judul utama (<h1>) dengan teks bebas.
  • Dua paragraf (<p>) yang menceritakan sesuatu tentang diri Anda.
  • Sebuah tautan ke situs favorit Anda.
  • Sebuah daftar tak berurutan dengan 3 hobi Anda.

Gunakan editor Live Preview di atas untuk menulis kode Anda. Anda bisa mengedit kode yang sudah ada atau mulai dari awal dengan menekan tombol Reset Kode dan menulis sendiri.
