🧠 Apa itu HTML?

Definisi HTML

HTML adalah singkatan dari HyperText Markup Language. Mari kita pecah definisi ini:

  • HyperText: Teks yang dapat berisi link (tautan) ke dokumen lain
  • Markup: Sistem penandaan konten menggunakan tag/elemen
  • Language: Bahasa yang memiliki aturan dan sintaks tertentu

Dengan kata lain, HTML adalah bahasa untuk membuat struktur konten web. HTML memberikan makna dan organisasi pada teks, gambar, link, dan elemen-elemen lain yang Anda lihat di halaman web.

HTML dalam Ekosistem Web

Web modern dibangun dengan kombinasi tiga teknologi utama yang bekerja bersama:

📊 Hubungan HTML, CSS, dan JavaScript 
HTML = Struktur & Konten (skeleton / kerangka)
CSS  = Tampilan & Styling (pakaian / dekorasi)
JS   = Interaksi & Logika (gerakan / tingkah laku)

Analogi: Membangun Rumah
─────────────────────────────
HTML = Kerangka rumah, dinding, pintu, jendela
CSS  = Cat tembok, wallpaper, furniture, dekorasi
JS   = Lampu yang menyala/mati, pintu otomatis, AC

Kenapa HTML Penting?

  • Struktur Semantik: Memberikan makna pada konten (judul, paragraf, list, dll)
  • Aksesibilitas: Membantu screen reader untuk pengguna dengan keterbatasan visual
  • SEO (Search Engine Optimization): Mesin pencari memahami konten lebih baik
  • Responsivitas Mobile: HTML yang benar mendukung desain responsive
  • Performa Web: HTML yang clean membuat halaman lebih cepat
  • Maintenance: Kode yang terstruktur mudah diperbaiki dan dikembangkan
✅
Kami menggunakan HTML5. Semua browser modern mendukung HTML5 sepenuhnya. Ketika mengatakan "HTML" di kursus ini, kami berarti HTML5 (standar terbaru sejak 2014).

3. Membuat File HTML Pertama

Ikuti langkah-langkah ini untuk membuat file HTML pertama:

  1. Buka VS Code dan buat folder baru bernama my-website
  2. File → New File, ketik nama index.html
  3. Ketik kode HTML (lihat bagian struktur dasar di bawah)
  4. Simpan file (Ctrl+S / Cmd+S)
  5. Klik kanan file → "Open with Live Server"
  6. Browser akan terbuka otomatis menampilkan halaman HTML Anda
⚠️
Perhatian: Pastikan file disimpan dengan ekstensi .html, bukan .txt atau format lain. Browser hanya mengenal file dengan ekstensi HTML.

🏗️ Struktur Dasar Dokumen HTML

Template HTML Minimal

Setiap dokumen HTML harus memiliki struktur dasar yang disebut "skeleton" atau "boilerplate". Berikut adalah struktur minimal yang valid:

📄 HTML 
<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Halaman Saya</title>
  </head>
  <body>
    <h1>Halo, Dunia!</h1>
    <p>Ini adalah halaman HTML pertama saya.</p>
  </body>
</html>

Penjelasan Setiap Bagian

<!DOCTYPE html> — Deklarasi Tipe Dokumen

Baris pertama yang WAJIB ada di setiap file HTML. Ini memberitahu browser bahwa file ini adalah dokumen HTML5. DOCTYPE hanya perlu ditulis sekali di awal file.

📄 HTML 
<!DOCTYPE html>

<html> — Elemen Root

Elemen <html> adalah kontainer induk yang mencakup seluruh dokumen. Atribut lang="id" memberitahu browser bahwa konten dalam bahasa Indonesia (baik untuk accessibility dan SEO).

📄 HTML 
<html lang="id">
  <!-- Seluruh konten halaman berada di sini -->
</html>

<!-- Pilihan bahasa lain: -->
lang="en"   <!-- English -->
lang="es"   <!-- Spanish -->
lang="fr"   <!-- French -->
lang="de"   <!-- German -->
lang="ja"   <!-- Japanese -->

<head> — Informasi Dokumen

Bagian <head> berisi informasi tentang halaman, bukan konten yang terlihat. Di sini kita definisikan metadata, judul halaman, link ke CSS, dll.

📄 HTML 
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Judul yang Muncul di Tab Browser</title>
  <meta name="description" content="Deskripsi halaman untuk SEO">
  <link rel="stylesheet" href="style.css">
  <script src="script.js"></script>
</head>

<body> — Konten yang Terlihat

Bagian <body> berisi semua konten yang terlihat di browser: teks, gambar, link, tombol, form, dll. Ini adalah bagian utama yang akan Anda lihat ketika membuka website.

📄 HTML 
<body>
  <h1>Judul Halaman</h1>
  <p>Paragraf pertama.</p>
  <p>Paragraf kedua.</p>
  <img src="gambar.jpg" alt="Deskripsi gambar">
  <a href="https://example.com">Link ke website lain</a>
</body>

🏷️ Meta Tags Penting

Meta tags adalah informasi khusus di dalam <head> yang memberitahu browser dan mesin pencari tentang halaman. Berikut meta tags yang paling penting untuk pemula:

1. Meta Charset — Encoding Karakter

Menentukan encoding karakter file. Selalu gunakan UTF-8 untuk mendukung semua bahasa (Indonesia, Emoji, Arab, Chinese, dll).

📄 HTML 
<meta charset="UTF-8">

2. Meta Viewport — Responsivitas Mobile

SANGAT PENTING untuk mobile devices. Tanpa ini, halaman akan terlihat kecil dan tidak responsif di smartphone.

📄 HTML 
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Penjelasan:
├─ width=device-width → Lebar halaman = lebar device
└─ initial-scale=1.0 → Zoom awal 100%

3. Meta Description — Deskripsi untuk SEO

Deskripsi singkat (max 160 karakter) yang muncul di hasil pencarian Google. Penting untuk SEO dan user experience.

📄 HTML 
<meta name="description" content="Belajar HTML dari nol dengan tutorial interaktif dan live preview">

4. Meta Keywords — Keyword untuk Mesin Pencari

Keyword yang relevan dengan halaman. Tidak sekritis dulu, namun masih berguna untuk SEO.

📄 HTML 
<meta name="keywords" content="HTML, web development, tutorial coding">

5. Meta Author — Penulis Halaman

Informasi tentang siapa yang membuat halaman ini.

📄 HTML 
<meta name="author" content="Nama Anda">

Contoh Lengkap: Head Section yang Profesional

📄 HTML 
<!DOCTYPE html>
<html lang="id">
<head>
  <!-- Encoding & Viewport (WAJIB) -->
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- Judul Halaman -->
  <title>Belajar HTML - VITH Education</title>

  <!-- SEO Metadata -->
  <meta name="description" content="Pelajari HTML dari nol dengan tutorial interaktif">
  <meta name="keywords" content="HTML, web development, tutorial">
  <meta name="author" content="Nama Anda">

  <!-- CSS Link -->
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <!-- Konten halaman -->
</body>
</html>

📌 Tips & Aksesibilitas

💡
Tip 1: Selalu mulai dengan skeleton. Jangan mulai coding langsung. Salin template minimal di atas terlebih dahulu, baru tambahkan konten. Ini menghemat waktu dan menghindari kesalahan.
💡
Tip 2: Gunakan Live Server untuk development. Extension Live Server di VS Code membuat browser auto-refresh setiap Anda save file. Ini jauh lebih efisien daripada manual refresh.
💡
Tip 3: Perhatikan indentasi (indentation). Indentasi membuat kode lebih readable. Gunakan 2 atau 4 spasi untuk setiap level nesting. VS Code bisa auto-indent dengan Shift+Alt+F.
💡
Tip 4: Gunakan semantic HTML. Alih-alih generik (seperti div), gunakan tag semantic seperti header, nav, main, footer. Ini membantu aksesibilitas dan SEO.
⚠️
Aksesibilitas: Meta viewport penting untuk pengguna mobile dan untuk accessibility. Selalu include <meta name="viewport"...> untuk responsive design.
✅
SEO Benefit: Meta tags (description, keywords, author) membantu mesin pencari memahami halaman Anda. Google menggunakan data ini untuk ranking dan tampilan di search results.

🏆 Mini Challenge

📝 Tugas Anda

Menggunakan editor Live Preview di atas, buatlah halaman HTML dengan struktur lengkap yang berisi:

  • Sebuah judul utama (<h1>) dengan nama Anda
  • Dua paragraf (<p>) berisi:
    • Paragraf 1: Tentang diri Anda (minimal 2 kalimat)
    • Paragraf 2: Alasan Anda belajar web development
  • Sebuah daftar (list) dengan 3-5 hobi atau keahlian Anda
  • Sebuah link ke website favorit Anda
  • Meta tags yang lengkap di head section (charset, viewport, title, description)
💡 Panduan:
  1. Mulai dengan skeleton template yang sudah ada di editor
  2. Ganti placeholder text dengan konten Anda sendiri
  3. Periksa hasil preview di sisi kanan editor
  4. Jika ada error, baca pesan error dengan teliti
  5. Gunakan tombol "Reset" jika ingin mulai dari awal

🎯 Kriteria Sukses

  • ✓ Kode valid tanpa error di console
  • ✓ Semua tag HTML ditutup dengan benar
  • ✓ Meta viewport dan charset ada di head
  • ✓ Minimal 3 paragraf atau list items
  • ✓ Setidaknya 1 link yang mengarah ke halaman eksternal
  • ✓ Indentasi yang rapi dan konsisten
⏰ Waktu: 15-20 menit. Jangan terburu-buru, fokus pada struktur yang benar!
